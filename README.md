# Tengrova — Destek ve gizlilik sayfaları

Tengrova (ucansogan games) için herkese açık destek ve gizlilik sayfaları.

Destek: ucansogan.games@gmail.com

## GitHub Pages

1. GitHub → + → New repository. Owner: karamane. Repository name: **tengrova-pages**. Visibility: Public.
2. Bu klasördeki `index.html`, `privacy.html`, `styles.css`, `icon.png`, `.nojekyll` ve `README.md` dosyalarını repo köküne yükleyip commit edin.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root) → Save.

Beklenen ana sayfa: https://karamane.github.io/tengrova-pages/
Beklenen gizlilik adresi: https://karamane.github.io/tengrova-pages/privacy.html

Adresler dağıtım bitince çalışır. Play Console'a girmeden önce gizlilik adresini oturum açılmamış (gizli) bir tarayıcı penceresinde kontrol edin.

## Kapsam

Gizlilik politikası; reklam, analiz, satın alma, hesap ve bulut kaydı olmayan Tengrova sürümünü anlatır. Bu tür bir hizmet eklenmeden önce metin güncellenmelidir. Site yalnızca yerel stil ve görsel kullanır; izleme betiği veya dış font yoktur.

Oyun kaynak kodu ve imzalama dosyaları bu siteye konmaz.
